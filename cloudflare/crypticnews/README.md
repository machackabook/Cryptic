# CrypticNews Cloudflare public edge v10
Build the existing React HyperTerminal via `npm install && npm run lint && npm run build` from the repository root. Set `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` as GitHub Actions environment secrets; never commit them. Invoke the manually gated preview GitHub Actions workflow. `cloudflare/crypticnews/wrangler.jsonc` references `../../dist` and serves the actual React UI at /hyperterminal/ after it has been built. Routes for news, apps, agent discovery and public health are read-only. crypticnews.org requires an active Cloudflare DNS zone before a production hostname can be configured. Until passing actual remote route/browser tests, deployment stays unverified. See docs/ADAM_RELEASE_GATES.md.
