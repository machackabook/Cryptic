# GEMINI.md — NEXUS/CRYPTIC repository operating contract
Scope: this repository, its agents, CI, deployed frontends, and edge gateway.
Read AGENTS.md and docs/ADAM_RELEASE_GATES.md before editing. Repository instructions guide agent behavior but are not authentication or an authorization grant.
Canonical public UI: Cryptic HyperTerminal at /hyperterminal/; protected service: SYNAPSE/aiohttp within the encrypted Nexus Enclave, never in a public Cloudflare Worker.
Proof-first: DISCOVER → OBSERVE → NORMALIZE → CLASSIFY → VERIFY → FINGERPRINT → LOOKUP_REMEDY → APPLY_REMEDY → REVERIFY.
Promotion: ORCHBENCH → LIVE_EXECUTION → ADAM_PROOF_GATES → PRODUCTION_VERIFIED → ARCHBENCHSHOP. Cain records immutable evidence, Abel independently verifies. A green UI indicator is not evidence.
No invented traffic, fake user accounts, fictional vulnerability scan claims, or 6,000 OS processes. 6,000 refers to logical registration slots until actual worker instances are attested.
Never commit secrets, JWTs, OAuth tokens, private chat logs, private thoughts, biometric data, private DNS values, personal files or API credentials. Use Cloudflare/GitHub secrets; redact outputs.
GitHub Pages and Cloudflare public surfaces: static assets only, no privileged command executor, arbitrary URL proxy or default-open telemetry endpoint.
No auto-merge, public visibility changes, destructive commands, OS imaging, device scans, remote shell, model calls or production deployment without explicit permission and passing relevant gates.
Review original design and integrate by small verified increments. Keep public sources and runtime-control-plane private boundaries explicit.
Documentation: docs/ADAM_RELEASE_GATES.md. Edge project: cloudflare/crypticnews/.
