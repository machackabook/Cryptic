## Mock-to-real correction

The historical file labels one panel **WSS DATA STREAMS**, but its implementation uses a timer to generate labels such as `wss://sys.omi`; it does not establish a real WebSocket.

The public Cryptic implementation preserves the visual/mechanical lineage while replacing that synthetic stream with real Cryptic ledger state, browser telemetry, message-route status, signed edge-gateway state, and public node-registry data.

## Current public implementation

`/magic/` uses HTMX 2.x fragment swaps so the surrounding browser/window remains mounted while Terminal, Telemetry, Communications, Nodes, Welcome Sentience, and Singularity surfaces change independently.

The top-left root control toggles clear-UI mode without destroying the visualizer or dashboard state.
